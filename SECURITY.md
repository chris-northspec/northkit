# Security

Report a security issue to **security@northspec.co.uk**. Please don't open a public issue.

We aim to acknowledge reports within 5 working days. Licence holders are notified of security updates by email.

Release requirements (from the NorthSpec standards):
- No release with a known critical or high-severity vulnerability.
- OWASP ASVS Level 1 as a minimum; OWASP Top 10 tested.
- Dependency and secret scanning in CI.
- Signed releases with published checksums.
